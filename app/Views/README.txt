TEMPLATE WEBSITE COMPANY PROFILE - TAILWIND CSS

Struktur:
- index.html              : Home
- tentang-kami.html       : Tentang Kami
- produk-layanan.html     : Produk dan Layanan
- gallery.html            : Gallery
- kontak.html              : Kontak
- assets/style.css         : CSS tambahan
- assets/site.js           : Header, navigasi, dan footer bersama

CARA MENJALANKAN:
1. Ekstrak folder company-profile-tailwind.
2. Buka index.html melalui browser, atau jalankan dengan ekstensi Live Server di VS Code.
3. Pastikan koneksi internet tersedia karena Tailwind CSS, Google Fonts, dan gambar contoh menggunakan CDN/URL eksternal.

PENYESUAIAN:
- Ganti teks NAMA PERUSAHAAN dan isi profil dengan data perusahaan.
- Ganti gambar Unsplash dengan foto perusahaan sendiri.
- Perbarui alamat, email, telepon, dan tautan media sosial.
- Formulir kontak saat ini hanya contoh tampilan; hubungkan ke backend atau layanan formulir agar pesan benar-benar terkirim.
- Tailwind CSS digunakan melalui CDN untuk memudahkan preview. Untuk website produksi, disarankan menggunakan Tailwind CLI/build process.
